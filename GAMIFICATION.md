# Litera — Guided Reading Quests (Phase 9)

This integration brings the three-area guided-practice experience from the supplied **DavaoLearn-AI(1).zip** into the **existing Phase 7/8 Litera landscape UI**. It does **not** replace the learner dashboard, teacher review screen, assessment workflows, Gmail sign-in, or adaptive scoring/decision tree.

## Learner experience

Open the **Practice** tab or the **Explore guided quests** action in **My next learning activity** to view **My Reading Journey**, a full-width card below the four existing student dashboard panels.

| Journey area | Skill | Learning materials |
| --- | --- | --- |
| Word Village | Phonics | Two guided CVCC final-`nt` blending/sound activities |
| Story Forest | Oral reading | *The Kite in the Hall*, guided passage reading and rereading |
| Meaning Mountain | Reading comprehension | *The Blue Lunch Box* and *The Library Book*, with meaning questions |

Students can choose any available practice area; Litera highlights one matching the server's **teacher-validated primary/secondary recommendation** when a compatible practice pack exists. Each activity displays instructions, progress, original practice reading material, multiple-choice or teacher-guided steps, three levels of **pre-authored hints**, corrective feedback, optional notes and a pause/resume action. Answers and hint use are recorded in the practice history, separate from formal assessments.

The original interactive content and practice-only assessment boundary are preserved. No content is generated by AI. The five included packs are provisional curriculum samples; have a teacher review them before classroom use.

### Gamification rules

- **★ Stars:** One star per **distinct completed activity ID** (repeating the same activity does not produce another star).
- **Practice XP:** 25 XP per distinct completed activity. Not redeemable, not grades, not a ranking.
- **Badges:** First Quest, Word Explorer, Story Adventurer, Meaning Detective, Three-Skill Explorer. Each badge is earned for doing related **practice**, not for being assessed as proficient.
- **Three zones:** show completion counts and a suggested next activity, without locking other reading areas.
- **Accessibility:** larger practice text, high contrast, focus reading, visible keyboard outlines, responsive layouts and reduced-motion preference. The original Litera page layout remains intact.
- **Completion:** a step-based activity must be completed to earn a star; clicking a simple "done" button no longer awards success.

**IMPORTANT:** Quests, practice XP, badges, guided hints and multiple-choice retries **never** generate assessment evidence, change SUPPORT/READY/UNCONFIRMED, or validate oral recordings. Existing teacher assessment reviews remain the only way to confirm official scores.

## Student and teacher synchronization

A new authenticated API saves progress in the same local machine's `.litera-data/practice.sqlite3`:

| Route | Access |
| --- | --- |
| `GET /api/student/practice` | Student cookie; own runs only |
| `PUT /api/student/practice/{run_id}` | Student cookie + same-origin check; own runs only |
| `GET /api/teacher/learners/{learner_id}/practice` | Teacher Key only |

Practice records contain learner/session ID, content ID/version, target skill/tier, step, attempts, hint history, optional note and completion timestamp. Server validation checks known activity IDs and authored answers, rejects identity mismatches, and makes completed runs immutable. The client retains a local-browser backup; use **Retry sync** if the server rejects or cannot receive a save. Teacher view marks the data **practice only**.

When a teacher selects a student's existing submission, **Learner progress and recommendations** shows that learner's synced quest history alongside official scores. This has no effect on teacher review permissions or recorded audio.

**Deployment warning:** Local SQLite and a shared teacher key are suitable only for the hackathon demonstration. Student practice records are personal learning data: use consenting participants, data-retention controls, per-teacher accounts, and appropriate hosted authorization before deploying for schools.

## Assessment handoff limitation

The **Choose a reading assessment** button returns to the existing student assessment choices after practice. It does **not** promise a fresh equivalent assessment form. Grade progression still requires the separate, teacher-validated independent assessment and the existing comparability/independence rules. The old DavaoLearn source's dedicated `fresh-check` form-exposure service was not directly copied because this Litera codebase handles assessment sessions and form inventory differently. Integrating that safely should be a separate assessment/evidence task.

## Windows run and update

1. Extract the new ZIP to a separate folder.
2. Copy the **old `.env`** and, while the old server is stopped, the **old `.litera-data` directory** into the new folder. Preserve the old directory as a backup.
3. From PowerShell run `./Start-Litera.cmd` (or `\.\Start-Litera.cmd` in Windows PowerShell).
4. Open student `http://127.0.0.1:8765/`, sign in, and open Practice. To review the history, open `/teacher` and enter your existing Teacher Key.

The new practice database is created automatically. No previous assessment database migration is needed.
